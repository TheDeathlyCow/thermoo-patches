# Origins Patch Automatically Integrated

The patch for Origins has been updated to *automatically* apply Thermoo Patches powers to the Blazeborn and Piglin
origins on start up - no manual configuration requires.

However, Thermoo Patches will only apply its powers to Origins if they are not being overriden by your own Datapack or
Mod, it will only patch power JSON files supplied by the Origins mod itself.

Origins added by any addon or datapack will not have these powers applied unless you add them.

- Piglin (Extra Origins): Increased heat resistance
- Blazeborn: Heat has no effect, reduced frost resistance, increased minimum temperature.
