# Thermoo Patches 5.1.0

Some new and updated patches, plus preparation for new Neoforge port.

- Thermoo Patches now provides the `thermoo_patches` mod ID, this is the mod ID that will be used by the Neoforge version.
- Added patch for Origins: Legacy
   - This is a mostly straightforward patch of the 1.21.1 Origins port, though the `can_freeze` and `can_heat` predicates have been removed as they are no longer necessary. 
- Re-added patch for Colorful Hearts
- The Serene Seasons patch now implements a listener for Thermoo's is cold enough to snow event.
- Converted all entry points to use the Yumi Minecraft Foundation Library.
