Updates Thermoo Patches to 1.21. The following patches have been updated:

- Colourful Hearts
- Serene Seasons
- Origins

The following patches have NOT been updated, because their mods have not been updated to this version. They will likely be incompatible when the respective mods update:
- Armor Points++ and libhud
- Overflowing Bars
- Fabric Seasons
- Immersive Weathering
- Ad Astra
- Extra Origins
- Mob Origins

A special case for Origins: this mod is going to introduce breaking changes in future alphas that will affect Thermoo Patches, and so this version is only compatible with Origins `1.13.0-alpha.5`. Future versions of Origins have been marked as breaking with Thermoo Patches for this reason.
