# Stellaris Patch and a Modular Rework

This release of Thermoo Patches includes a new patch for [Stellaris](https://modrinth.com/mod/stellaris) and ships a large internal refactor that has split the mod into a multi-module project. 

* Fixed Origins patch not applying Environmental Resistances and updated Origins temperature effects
* Added a new integration Patch for [Stellaris](https://modrinth.com/mod/stellaris).
* This patch is, as always, completely optional.
* The Stellaris patch makes each planet and celestial object have a temperature (and humidity) that roughly corresponds to its real life temperatures. All planets except for Venus have different temperatures for day and night. 
* These temperatures are as follows:
    * The Moon (Day): 400K, 0% humidity
    * The Moon (Night): 140K, 0% humidity
    * Mars (Day): 293K, 0.01% humidity
    * Mars (Night): 210K, 100% humidity
    * Mars (Day, Ice Spikes): 210K, 50% humidity
    * Mars (Night, Ice Spikes): 120K, 100% humidity
    * Venus (Day & Night): 737K, 0.01% humidity
    * Mercury (Day): 700K
    * Mercury (Night): 140K
* The mod has also undergone a major refactor that has split each patch into its own "sub mod" of the larger Thermoo Patches. I have tested this change as thoroughly as I can, but if there is something wrong do not hesitate to report it at https://github.com/TheDeathlyCow/thermoo-patches/issues
* As part of this change, the Armor Points++ and Immersive Weathering patches have been disabled, though not removed. I will update and re-enable these patches if and when those mods update.
* Because the Armor Points++ and Immersive Weathering patches have been disabled, Thermoo Patches is no longer incompatible with those mods, yay!
